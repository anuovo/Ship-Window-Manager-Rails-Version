Monthly Grid Reference

Static HTML/CSS handoff for developers to bind to an existing database.

Developer Notes

  • Yellow rows are derived ship window availability rows.
  • Green item cells mean that specific item is assigned to that ship window for that month.
  • Blank cells mean no availability for that item/month combination.
  • Sticky first two columns and sticky month header row are included in CSS.
  • Replace the sample rows below with rows generated from your existing database.
